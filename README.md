# E-Commerce Customer Churn & Retention Analytics

## 📌 Project Overview

This project analyzes an e-commerce business using customer, order, product, seller, payment, and review data to understand sales performance, customer behavior, product performance, seller performance, and potential customer retention opportunities.

The project follows an end-to-end data analytics workflow using **Excel, SQL, Python, and Power BI**.

---

## 🎯 Business Objective

The main objective is to transform raw e-commerce data into actionable business insights that can help the business:

- Understand overall sales and order performance
- Analyze customer purchasing behavior
- Identify important customer segments
- Identify high-performing product categories
- Evaluate seller performance
- Analyze payment methods and order status
- Identify potential customer retention opportunities
- Support data-driven business decisions

---

## 🏢 Business Questions

This project focuses on questions such as:

1. How many orders were placed and delivered?
2. How are orders changing over time?
3. Which product categories generate the most sales?
4. Which sellers contribute the most sales?
5. Which customers generate the highest revenue?
6. Which payment methods are most commonly used?
7. What is the distribution of order statuses?
8. Which areas of the business require improvement?
9. What factors may contribute to customer churn or reduced retention?
10. What actions can the business take to improve customer retention?

---

## 📊 Dataset

The project uses the **Brazilian E-Commerce Public Dataset by Olist**.

The dataset contains multiple related tables covering:

- Customers
- Orders
- Order Items
- Products
- Sellers
- Payments
- Reviews
- Geolocation

The data covers approximately **100K e-commerce orders** and provides information about customer transactions, products, sellers, payments, delivery, and reviews.

> Large raw files are excluded from this GitHub repository using `.gitignore` because of GitHub file-size limitations.
